# 000. Record architecture decisions

Date: 2026-11-10
Status: Accepted

## Context
Decisions about tooling, architecture, spec changes and business choices need to be traceable across sessions.

## Decision
Record each significant decision as a numbered Markdown file in `docs/decisions/` (`NNN-short-title.md`) with Context, Decision and Consequences sections. Superseded ADRs stay in place with their status updated.

## Consequences
Anyone (including a fresh Claude Code session) can read why things are the way they are without digging through chat history.
